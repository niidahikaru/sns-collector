# Threads投稿収集ツール セットアップ手順

Threads（threads.net）の特定アカウントの投稿を自動収集し、Googleスプレッドシートに書き込むツールです。

## 注意事項

- このツールはThreadsのDOM（画面表示）からデータを読み取る方式です
- Threadsの画面構造が変更された場合、正常に動作しなくなる可能性があります
- Threads利用規約のグレーゾーンに該当する可能性があるため、利用は自己責任でお願いします
- 大量のスクロールはブラウザのメモリを消費します。必要に応じてブラウザを再起動してください

## 出力フォーマット

スプレッドシートには以下の5列で記録されます。

| 列 | 内容 | 例 |
|---|---|---|
| A | 投稿日時 | 2025/01/15 14:30 |
| B | 投稿内容 | 本文テキスト |
| C | いいね数 | 123 |
| D | インプ数 | 4500 |
| E | 画像の有無 | あり / なし |

## Step 1: Googleスプレッドシートの準備

1. [Google スプレッドシート](https://sheets.google.com) を開く
2. 「空白のスプレッドシート」で新しいシートを作成
3. シート名を任意に変更（例：「Threads収集データ」）
4. **スプレッドシートのURLまたはIDをメモ**しておく（後で使います）

## Step 2: Google Apps Script のセットアップ

1. 作成したスプレッドシートで、メニューの **「拡張機能」→「Apps Script」** をクリック
2. Apps Scriptエディタが開いたら、既存のコード（`function myFunction()...`）を全て削除
3. `gas_code.gs` の内容を全てコピーして貼り付ける
4. **Ctrl+S（Cmd+S）** で保存
5. プロジェクト名を任意に変更（例：「Threads収集」）

### Webアプリとしてデプロイ

1. 右上の **「デプロイ」→「新しいデプロイ」** をクリック
2. 歯車アイコンから **「ウェブアプリ」** を選択
3. 以下の設定にする：
   - **説明**: Threads投稿収集（任意）
   - **次のユーザーとして実行**: 自分
   - **アクセスできるユーザー**: **全員**
4. **「デプロイ」** をクリック
5. 初回はGoogleアカウントへのアクセス許可を求められるので **「許可」** をクリック
   - 「このアプリは確認されていません」と表示されたら、**「詳細」→「〇〇（安全ではないページ）に移動」** をクリック
6. 表示された **「ウェブアプリ URL」をコピー** して控える
   - `https://script.google.com/macros/s/xxxxxxx/exec` という形式

> デプロイURLはChrome拡張に設定するので、必ずコピーしておいてください。

## Step 3: Chrome拡張のインストール

1. 以下の4ファイルが同じフォルダにあることを確認：
   - `manifest.json`
   - `content.js`
   - `popup.html`
   - `popup.js`

2. Chromeで `chrome://extensions` を開く

3. 右上の **「デベロッパーモード」をON** にする

4. **「パッケージ化されていない拡張機能を読み込む」** をクリック

5. 上記4ファイルが入っている **フォルダを選択**

6. 「Threads投稿収集」がインストールされたことを確認

## Step 4: 拡張機能の設定

1. Chromeのツールバーにある **拡張機能アイコン（パズルピース）** をクリック
2. 「Threads投稿収集」の **ピン留め** をONにする（任意）
3. 「Threads投稿収集」のアイコンをクリックしてポップアップを開く
4. **「Google Apps Script URL」** の欄に、Step 2でコピーしたデプロイURLを貼り付ける
   - URLは自動保存されます

## Step 5: 投稿の収集

1. Chromeで **threads.net** を開き、収集したいアカウントのプロフィールページに移動
   - URL例: `https://www.threads.net/@username`

2. 拡張機能のアイコンをクリックしてポップアップを開く

3. **「収集開始」** ボタンをクリック
   - 自動でページが下にスクロールし、投稿が読み込まれます
   - 取得件数がリアルタイムで表示されます
   - リプライは自動的に除外されます

4. 必要な分だけ収集できたら **「収集停止」** ボタンをクリック

5. **「スプレッドシートに送信」** ボタンをクリック
   - 収集したデータがGoogleスプレッドシートに書き込まれます
   - 重複する投稿は自動的にスキップされます

6. Googleスプレッドシートを開いてデータが書き込まれたことを確認

## トラブルシューティング

### 「ページを再読み込みしてから再試行してください」と表示される
- threads.net のページを **F5キーで再読み込み** してから、再度ポップアップを開いてください

### 投稿が1件も取得できない
- threads.net のDOM構造が変更された可能性があります
- `content.js` のセレクタ部分の修正が必要になる場合があります
- ブラウザのDevTools（F12）→ Console タブで `[Threads収集]` のログを確認してください

### スプレッドシートに送信できない
- GAS URLが正しいか確認してください
- GASのデプロイ設定で「アクセスできるユーザー」が「全員」になっているか確認してください
- GASを再デプロイする場合は、**「デプロイを管理」→「新しいデプロイ」** から新しいURLを取得し、拡張機能に再設定してください

### 収集に時間がかかる・ブラウザが重くなる
- 大量のスクロールはメモリを消費します
- 一度に数百件程度を目安に収集し、適宜ブラウザを再起動してください

---

## GASコードの更新時

GASのコードを更新した場合は、必ず **新しいデプロイ** を作成してください。既存のデプロイを「編集」しても反映されません。

1. Apps Script エディタでコードを更新・保存
2. **「デプロイ」→「新しいデプロイ」** で新しいURLを取得
3. Chrome拡張のポップアップで新しいURLに更新
