====================================
Threads投稿収集ツール セットアップ手順
====================================

■ 必要なもの
  - Google アカウント
  - Google Chrome
  - Node.js（https://nodejs.org/）

■ セットアップ手順

Step 1: フォルダを展開する
  ダウンロードした ZIP ファイルを展開してください。

Step 2: セットアップスクリプトを実行する
  ターミナル（Mac）またはコマンドプロンプト（Windows）で
  展開したフォルダを開き、以下を実行します:

    node setup.mjs

  → 画面の指示に従って Google アカウントにログインしてください。
  → 初回のみ Apps Script API の有効化が必要です:
    https://script.google.com/home/usersettings

  途中で「GASの権限を認可してください」と表示されます。
  画面に表示されるURLを開き、以下の手順で認可してください:

  1. エディタ上部の「実行」ボタン（▶）を押す
  2. 「承認が必要です」→「権限を確認」をクリック
  3. 「このアプリは Google で確認されていません」と表示される
     → 左下の「詳細」をクリック
     → 「Threads投稿収集（安全ではないページ）に移動」をクリック
     ※ 自分で作成したスクリプトなので安全です
  4. 「続行」を押して権限を許可
  5. ターミナルに戻って Enter を押す

Step 3: Chrome拡張をインストールする
  1. Chrome で chrome://extensions を開く
  2. 右上の「デベロッパーモード」をONにする
  3. 「パッケージ化されていない拡張機能を読み込む」をクリック
  4. → 展開したフォルダ内の extension フォルダを選択

Step 4: 投稿を収集する
  1. Threads（または X）のプロフィールページを開く
  2. Chrome右上の拡張アイコンをクリック
  3. 「収集開始」ボタンをクリック
  4. → 自動スクロールで投稿が収集されます
  5. → 収集データは自分の Google スプレッドシートに保存されます

■ スプレッドシートの確認方法
  extension/config.json を開くとURLが記載されています。
  または Google ドライブで「Threads投稿収集」を検索してください。

■ トラブルシューティング

Q: 「Apps Script API が有効になっていません」と表示される
A: 以下のURLにアクセスし、APIを有効にしてください:
   https://script.google.com/home/usersettings

Q: ログインがうまくいかない
A: node setup.mjs をもう一度実行してください。

Q: 「このアプリは Google で確認されていません」と表示される
A: 自分のアカウントで作成したスクリプトです。
   「詳細」→「Threads投稿収集（安全ではないページ）に移動」で
   進めてください。

Q: 収集データはどこに保存されますか？
A: セットアップ時に自動作成された「Threads投稿収集」という
   Google スプレッドシートに保存されます。
   Google ドライブで確認できます。
